### <a name="_qmphm5d6rvi3"></a>**Решение**

Так как получение ставок в собтсвенном кол-центре было описано в прошлом ADR, здесь остановимся только на передаче ставок в партнерский кол-центр.

Есть техническое ограничение, не позволяющее нам настроить прямую интеграцию между нашими системами и партнерским кол-центром. Поэтому возможен только один способ передачи - файлом.
У нас уже есть прошлая ADR, где предлагается вычислять ставки в новом сервисе core-banking-deposit. Остается только добавить в этом сервисе возможность формированя файла.
Дорабатываем core-banking-deposit и делаем кнопку на фронте АБС, чтобы сотрудники могли заказывать выгрузку. 

Решение максимально простое и дешевое в реализации.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

Делать отдельный сервис для формирования файлов - для одной задачи это будет избыточным. Сервис не будет нагруженным, его функциональность будет слишком узкая.

Не дорабатывать клиент на delphi, делать новый - дорого

**Недостатки, ограничения, риски**

Может так получиться, что клиент на delphi будет признан устаревшим и его нужно будет замещать чем-то более актуальным. Тогда мы потратим некоторые усилия на доработку клиента, который все равно будет утилизирован
